QUALIFICATION

IQ, OQ and PQ — What Each Stage Should Actually Demonstrate

The labels are familiar. The useful question is what evidence each stage is supposed to add to the qualification decision.

Qualification lifecycleIQ / OQ / PQPractical documentation

In pharmaceutical qualification, IQ, OQ and PQ should not be treated as three folders that simply need to be completed. Each stage answers a different technical question. When those questions are kept separate, protocols become easier to write, execution is easier to review and the final conclusion becomes much more defensible.

IQ: Was the system installed as intended?

Installation Qualification should establish that the equipment or system has been installed in accordance with the approved design, technical requirements and relevant manufacturer information. The focus is evidence about configuration, identity and installation.

Typical IQ evidence can include equipment identification, component checks, drawings, materials of construction, utilities, calibration status, manuals, certificates, software or firmware identification where relevant, and confirmation that required documentation is available.

Useful IQ question: If somebody unfamiliar with the installation reviewed this package, could they understand what was installed, how it is configured and whether the documented installation matches the intended design?

OQ: Does the system operate across the defined operating range?

Operational Qualification moves from installation evidence to functional evidence. The purpose is to challenge important functions, alarms, interlocks, controls and operating ranges under controlled test conditions.

Good OQ testing is not a repeat of normal production. It should deliberately demonstrate that defined functions work, that critical operating parameters can be controlled and that the system behaves acceptably at relevant limits or challenge conditions.

Acceptance criteria should come before execution

One of the most common weaknesses in qualification documentation is an acceptance criterion that is only obvious after the test has been performed. A protocol should state what constitutes an acceptable result before execution. That makes the test objective and reduces ambiguity during review.

PQ: Does the system perform consistently for its intended use?

Performance Qualification should demonstrate performance in conditions that meaningfully represent routine use. The emphasis shifts from individual equipment functions to the ability of the qualified system or process to achieve the intended result consistently.

Depending on the system, PQ may involve representative loads, worst-case conditions, repeated runs, process materials, routine operators or other conditions that connect the qualification exercise to actual use.

Useful PQ question: Does this evidence show that the system can repeatedly perform its intended GMP function under appropriately representative or challenging use conditions?

The stages should connect — but not duplicate each other

The strongest qualification packages use traceability across the lifecycle. Requirements lead to tests, risks influence test depth and deviations are assessed against the intended state. But traceability does not mean repeating the same check in IQ, OQ and PQ.

For example, confirming that a calibrated temperature sensor is installed is an IQ activity. Challenging a temperature-control function over its defined range is an OQ activity. Demonstrating that the process achieves the required result during representative operation is a PQ activity. The same technical theme may appear throughout the lifecycle, but the question changes at each stage.

What the final qualification report should do

The final report should not merely state that IQ, OQ and PQ were completed. It should explain whether the approved scope was executed, how deviations were resolved, whether acceptance criteria were met and whether the accumulated evidence supports release of the equipment or system for its intended use.

That conclusion is the real purpose of the qualification package. The individual protocols are evidence. The report turns that evidence into a controlled GMP decision.
